Check your download

In PowerShell, in the folder where the file is, run:

Get-FileHash .\localSpace-0.2.0-920b7123-windows-x64-setup.exe -Algorithm SHA256

Compare the result with the SHA-256 above. If the two values differ, don't run the file.

What it needs

Windows 10 or 11, 64-bit. Models download separately inside the app: a few GB, chosen for your computer.

Measured: Qwen3.5 4B: about 6–7 tokens per second (English answers) on a Core i7 laptop with Intel Iris Xe graphics, no NVIDIA card, 8 GB of memory, with a browser and VS Code open.

If Windows stops the installer

If Windows says “Windows protected your PC”, click More info, then Run anyway.

If Windows won’t open the installer. Some computers have Smart App Control turned on, and it may stop programs from new publishers. localSpace isn’t signed yet, so this can happen. We’re working on it. You can check the download is genuine with the SHA-256 above. We don’t recommend turning Smart App Control off.
